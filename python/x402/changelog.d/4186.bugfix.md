Fixed EVM batch-settlement channel managers claiming or refunding channels of another network that shares the same channel storage. `Channel` now carries an optional `network` that server hooks persist from the request requirements; claim, refund, idle-refund, selector and pending-withdrawal selection use it first and fall back to the channel-id binding for rows written without one. A failed claim batch no longer blocks later batches or the settlement of successful claims: `claim` and `claim_and_settle` now raise `BatchClaimError` exposing the batch `errors`, successful `results` and any completed `settle`, and the automatic claim job reports both the successful batches and the failure.
