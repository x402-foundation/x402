`x402[svm]` now requires `solders>=0.29.0` and `httpx`, and no longer installs `solana`: every `solana` release that supports Python 3.10 pins `solders` below 0.28, which cannot decode transaction version 1. The SVM mechanism talks JSON-RPC through the new `x402.mechanisms.svm.rpc.SvmRpcClient`. The facilitator signer signs `to_bytes_versioned(message)`, which applies the right prefix for legacy, version 0 and version 1 messages, and the private `FacilitatorKeypairSigner._is_versioned_transaction` helper is removed.
