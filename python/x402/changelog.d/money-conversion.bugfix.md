Parse and convert money as decimal strings internally so high-precision prices (for example MegaUSD at 18 decimals) are not rounded through `float`. `parse_money` / `parse_money_string` return the extracted decimal substring; money parsers now take `str | int | float` (`parse_price` always passes a string). Amounts smaller than one atomic unit truncate to `"0"` instead of raising. Note: the money-parser amount type is a breaking change for custom parsers that assumed `float`.
