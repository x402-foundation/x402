The SVM mechanism now talks JSON-RPC over `httpx` (`mechanisms/svm/rpc.py`) instead of depending on `solana-py`, whose synchronous client cannot be used with the `solders` 0.29 release that decodes transaction version 1. `x402[svm]` requires `solders>=0.29.0` and `httpx`, and no longer installs `solana`. Facilitator signing now serializes the message through `to_bytes_versioned`, which applies the correct version prefix for legacy, version 0 and version 1 rather than assuming version 0.
