The FastAPI and Flask payment middlewares now add `PAYMENT-REQUIRED` and `PAYMENT-RESPONSE` to `Access-Control-Expose-Headers` on every response that carries one of them, so cross-origin browser clients can read the 402 challenge and the settlement receipt. An expose list already on the response is merged case-insensitively instead of being replaced, and `Access-Control-Allow-Origin` is never set. In Flask the 402 itself carries the header, since it is returned before `after_request` hooks (and flask-cors) run.
