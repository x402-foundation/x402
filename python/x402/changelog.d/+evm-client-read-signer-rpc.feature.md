EVM `exact` and `upto` clients (`ExactEvmScheme`, `UptoEvmScheme`) take an optional `RPCConfig` (`rpc_url`, `rpc_by_chain_id`) that supplies onchain reads when the signer cannot read the chain. The Permit2 allowance check for gas sponsoring now runs over that RPC fallback, so the client skips signing an unnecessary EIP-2612 permit or ERC-20 approval when the allowance is already sufficient. A signer can report `has_rpc_client() -> False` to opt into the fallback. New exports: `RPCConfig`, `RPCChainConfig`.
