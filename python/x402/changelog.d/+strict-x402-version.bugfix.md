x402Version is now validated as a JSON number: detect_version, detect_payment_required_version and the V2 PaymentPayload, PaymentRequired, VerifyRequest and SettleRequest models accept an integer or a whole-number float (JSON has no integer type, so 2.0 is the same value as 2) and reject booleans, strings and fractional numbers, which were previously coerced to a protocol version.
