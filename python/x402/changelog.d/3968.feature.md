Added multi-payee splits to the SVM `exact` scheme (`extra.splits`, `ataCreationRequired`). The client builds one `TransferChecked` per leg plus fee-payer-funded `CreateIdempotent` for marked recipients, and refuses splits unless `approve_splits` consents. The server rejects split terms the facilitator does not advertise. The facilitator advertises `maxSplits` / `ataCreationSponsored` only when configured with `max_splits` / `ata_creation_sponsored` and verifies split charges on the static layout. Split charges work on transaction versions 0 and 1.
