Fixed EIP-3009 payment authorizations signing against the wrong EIP-712 domain (asset address instead of a seller's custom settlement contract, e.g. Circle Gateway) for sellers using a custom settlement contract. Trusting `extra.verifyingContract` is opt-in via a `verifying_contract_validator` callback passed to `ExactEvmScheme`/`ExactEvmSchemeV1`; by default (no validator supplied) signing still always uses the asset address, matching prior behavior.
