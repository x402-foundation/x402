The SVM exact facilitators (`ExactSvmScheme`, `ExactSvmSchemeV1`) and `register_exact_svm_facilitator` take `transaction_versions` (default `[0, 1]`): the message versions they accept and advertise as `extra.transactionVersions`. Pass `[0]` to keep a sponsor whose signer or RPC does not handle version 1 on version 0; any other version is rejected with `unsupported_transaction_version`, and legacy is accepted exactly when 0 is. New helper: `normalize_accepted_transaction_versions`; `is_accepted_transaction_version` takes an optional accepted set.
