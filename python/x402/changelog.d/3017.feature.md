Added an XRPL mechanism for the `exact` payment scheme, covering the client, resource server and facilitator. The payer signs an XRPL `Payment` that carries its own fee, so the facilitator holds no keys; verification enforces the scheme's rules offline and simulates against the ledger before accepting, and settlement waits for a validated `tesSUCCESS` with a per-process duplicate-settlement guard. Supports XRP and issued currencies on mainnet, testnet, devnet and custom XRPL networks. Install with `x402[xrpl]`.
