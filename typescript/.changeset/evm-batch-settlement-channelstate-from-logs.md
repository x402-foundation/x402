The batch-settlement facilitator now derives the deposit and refund settle `extra.channelState` from the confirmed receipt's `Deposited`, `Claimed` and `Refunded` events plus the pre-transaction state, instead of polling channel state after confirmation. A deposit receipt without a `Deposited` event for the channel fails with `invalid_batch_settlement_evm_deposit_transaction_failed`, and a receipt whose `logs` field is missing fails with the new `invalid_batch_settlement_evm_receipt_logs_unavailable`; both are terminal. A failed pre-refund channel read now rejects with `invalid_batch_settlement_evm_rpc_read_failed` before broadcast. The refund `withdrawRequestedAt` now survives a partial withdrawal reduction and `totalClaimed` comes from the bundled `Claimed` event. Voucher verify re-reads channel state after each `CHANNEL_STATE_REREAD_DELAYS_MS` wait (at most three re-reads) while the balance cannot cover `maxClaimableAmount`, and the server deposit and refund after-settle hooks never lower a stored `totalClaimed` or `refundNonce`. The deposit hook also never lowers `withdrawRequestedAt`; a refund snapshot of 0 still clears it. An omitted `channelState` field keeps the stored value. A deposit reconcile whose follow-up channel read fails still returns `channelState.balance` from `Deposited.newBalance` and omits the fields that event does not carry. A refund uses a same-receipt `Deposited.newBalance` and subtracts one following `Refunded`. Otherwise balance is the pre-read minus `Refunded.amount`, and a negative result omits `balance`. The refund after-settle hook deletes a channel only when that response includes a balance at or under the charged total. `BatchSettlementEvmScheme` (facilitator) now takes a `BatchSettlementFacilitatorEvmSigner`, whose `waitForTransactionReceipt` returns required `logs`; this is type-only, signers built with `toFacilitatorEvmSigner` over a viem client already conform, and a custom signer that declares `logs` optional must make it required. The `channelState` wire shape is unchanged.
