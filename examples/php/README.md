# PHP examples

Runnable examples for the [`php/`](../../php) SDK.

| Example | What it shows |
|---|---|
| [`servers/basic`](./servers/basic) | Gating a route with `PaymentMiddleware` |
| [`clients/basic`](./clients/basic) | Paying a 402 with `PaymentClient` |

Both need PHP 8.2+ and `composer install` in the example directory.
